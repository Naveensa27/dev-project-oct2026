# DevOps PulseApp/Project-oct-2026

A production-style end-to-end DevOps portfolio project demonstrating infrastructure provisioning, containerization, Kubernetes orchestration, CI/CD, and observability.

## Technologies Used
- **Cloud & IaC:** AWS (VPC, EKS, ECR), Terraform
- **Configuration & Containerization:** Docker, Ansible
- **Orchestration & CI/CD:** Kubernetes (Deployments, Services, HPA), GitHub Actions
- **Observability:** Prometheus, Grafana
